15.1Prior, likelihood, posterior

Prior p(θ) — what's known before data.
Likelihood L(θ)=p(y∣θ) — same object as in the MLE page.
Posterior p(θ∣y) = p(y,θ)∫p(y,θ)dθ ∝ L(θ)p(θ)

The denominator (the "evidence") is exactly the unknown normalizing constant C from the MCMC page — this is why MCMC exists: to sample p(θ∣y) without ever computing that integral.

15.2Worked example — Normal-Normal conjugacy

y∣θ ∼ N(θ,σ²), prior θ∼N(0,100). The joint (y,θ) is bivariate normal, giving a closed-form posterior:

θ∣y ∼ N(100y100+σ², 100σ²100+σ²)

Interpretation: small σ (informative data) ⇒ posterior ≈ the data (E(θ∣y)≈y); large σ (noisy data) ⇒ posterior ≈ the prior (E(θ∣y)≈0). Use the posterior directly for probability statements — P(θ>0), a 95% interval as the 2.5%/97.5% quantiles — with no "repeated sampling" story needed, unlike a frequentist CI.

15.3Recognizing conjugate posteriors from the log-kernel shape

Same recognition table as the MCMC/Gibbs page §14.7 — this is the exact skill both topics share, since a Gibbs sampler's conditionals are Bayesian posteriors:

a+b·log(θ)+cθ ⇒ Gamma(b+1,−1/c)  →  classic Gamma–Exponential and Gamma–Poisson conjugate pairs
a+bθ+cθ² ⇒ N(−b/2c,−1/2c)  →  Normal–Normal

15.4Worked example — Gamma prior, exponential-type likelihood

h23/h25-style: data with likelihood kernel L(θ)∝θⁿe−θc (for some data-dependent constant c), prior θ∼Gamma(a,b) (shape a, scale b):

log g(θ) = n·log(θ) − θc + (a−1)log(θ) − θ/b = (n+a−1)log(θ) − θ(c+1/b)

⇒ θ∣y ∼ Gamma(n+a, 1/(c+1/b))  — conjugate, closed form, no MCMC needed.

The moment you can write the log-posterior kernel as const+b′log(θ)+c′θ, stop — you already know the answer is Gamma; don't integrate anything.

15.5Worked example — a genuinely two-block posterior

v24-style: Ti∼Exponential(ab) iid, independent priors a∼Exp(3), b∼Exp(3). The joint posterior kernel:

p(a,b∣t) ∝ (ab)ⁿ·e−ab·Σti·e−3(a+b)

Fixing b and reading the shape in a only: n·log(a) − a(b·Σti+3) — a Gamma shape again:

a∣b,t ∼ Gamma(n+1, 1/(bΣti+3)),  and symmetrically  b∣a,t ∼ Gamma(n+1, 1/(aΣti+3))

Two simple Gamma conditionals — feed straight into a Gibbs sampler (MCMC page §14.7–14.8).

15.6Worked example — non-conjugate posterior needs MCMC

v26-style: yi∣μ,σ² ∼ N(μ,σ²) iid, μ∣σ²∼N(m₀,σ²/κ₀) (conjugate for μ), but the prior on variance is log(σ²)∼N(0,1) instead of the conjugate Inverse-Gamma. Consequences:

  • μ∣σ²,y is still Normal (Normal-Normal conjugacy on μ survives regardless of the prior on σ²) — closed form, sample directly.
  • σ²∣μ,y is not a standard distribution — the (log σ²)² term from the prior doesn't match any entry in the recognition table — needs a Metropolis step within the Gibbs sampler (a "Metropolized Gibbs sampler", see MCMC page §14.7).
This is the general pattern behind "is this conjugate?" questions: check each block's conditional against the recognition table separately — a model can be conjugate in one parameter and not in another.

15.7Using the posterior

P(θ>0∣y) = ∫₀∞ p(θ∣y)dθ  ·  95% interval: the 2.5%/97.5% quantiles of p(θ∣y) directly

Derived quantity η=k(θ): if closed-form, transform the distribution directly (e.g. η=θ+273.15 shifts a Normal posterior's mean only); otherwise apply k to MCMC samples and summarize the transformed sample.

15.8Common exam pitfalls

  • "Derive the posterior kernel" means: multiply likelihood × prior, take logs, drop every additive term that doesn't involve θ — don't try to track the normalizing constant.
  • Match a derived log-kernel against the recognition table term-by-term (coefficient of log(θ), coefficient of θ) rather than guessing the distribution from the model's "story".
  • A Bayesian 95% interval is a direct probability statement about θ — resist the urge to describe it with frequentist "repeated sampling" language.
