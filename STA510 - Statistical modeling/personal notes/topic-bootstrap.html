5.1Idea and algorithm

Given data x₁,…,xn and an estimator θ̂=g(x₁,…,xn), the non-parametric bootstrap treats the observed data as a stand-in for the whole population:

  1. Draw a resample of size n with replacement from x₁,…,xn.
  2. Compute the same estimator on the resample: θ̂*b.
  3. Repeat steps 1–2 a large number of times B (e.g. 2000–4000).
  4. Use the empirical distribution of θ̂*₁,…,θ̂*B as a stand-in for the true sampling distribution of θ̂.
B <- 4000
boot.est <- numeric(B)
for(i in 1:B){
  x.star     <- sample(x, size = length(x), replace = TRUE)
  boot.est[i] <- my.estimator(x.star)   # same formula as theta.hat, applied to the resample
}

5.2Bias, SE, MSE, bias-corrected estimate

biasboot = θ̂* − θ̂  (mean of the bootstrap replicates minus the original estimate)

SEboot = sd(θ̂*₁,…,θ̂*B)

MSEboot = Var(θ̂*) + bias²boot  (plus, not minus — a frequent slip)

Bias-corrected estimate: θ̂bc = θ̂ − biasboot = 2θ̂ − θ̂*

5.3Three confidence intervals — know all three cold

Normal:  θ̂ ± zα/2·SEboot

Percentile:  [qα/2,\; q1−α/2] — the raw empirical quantiles of the bootstrap distribution, used directly

Basic (reverse-percentile):  [2θ̂ − q1−α/2,\; 2θ̂ − qα/2] — reflects the percentile interval around θ̂
The single easiest thing to mix up: Basic subtracts the quantiles from 2θ̂ and swaps their order (upper quantile subtracted to get the lower bound); Percentile just uses the quantiles as-is. If a bootstrap distribution is skewed, all three intervals will visibly disagree — that disagreement is itself something exams ask you to comment on.

5.4Fully worked example — all three CIs (h25)

Rainfall data, n=40, Exponential(β) model, β̂=X=9.29mm. B=4000 bootstrap means give mean(θ̂*)=9.277269, sd(θ̂*)=0.5502607, and quantiles q2.5%=8.18, q97.5%=10.36.

bias = 9.277269 − 9.29 = −0.0127  ·  MSE = 0.5502607² + (−0.0127)² ≈ 0.30295
bias-corrected: θ̂bc = 2(9.29) − 9.277269 = 9.3027

Normal 95%:  9.29 ± 1.96(0.5503) = [8.21,\ 10.37]
Percentile 95%:  [8.18,\ 10.36]  (read straight off the quantiles)
Basic 95%:  [2(9.29)−10.36,\ 2(9.29)−8.18] = [8.22,\ 10.40]

All three land close together here because the bootstrap distribution is nearly symmetric — the giveaway is that mean(θ̂*)≈β̂ and Normal/Percentile/Basic barely differ.

5.5When the three CIs visibly disagree (v24)

n=20 lifetimes, θ̂=0.481. Bootstrap gives mean(θ̂*)=0.498, median(θ̂*)=0.485, sd(θ̂*)=0.101, q5%=0.361, q95%=0.686.

bias = 0.498−0.481 = 0.017  ·  MSE = 0.101² + 0.017² ≈ 0.01049

90% Normal:  0.481 ± 1.6449(0.101) = [0.315,\ 0.647]
90% Percentile:  [0.361,\ 0.686]
Comment expected here — the two 90% intervals are shifted relative to each other (Normal centered on θ̂, Percentile shifted right toward the bootstrap mean/median). Since mean(θ̂*)=0.498 > median(θ̂*)=0.485 > θ̂=0.481, the bootstrap distribution is right-skewed — exactly why the symmetric Normal interval disagrees with Percentile, and why Percentile (which makes no symmetry assumption) is generally preferred whenever skew is visible like this.

5.6A near-symmetric case for contrast (h22)

KDE-based density estimate θ̂=0.383733 at a point, B=2000, mean(θ̂*)=0.384128, var(θ̂*)=0.0010266 (note: variance, so SE=√0.0010266=0.03204), q2.5%=0.327, q97.5%=0.449.

bias ≈ 0.000395 (negligible)  ·  MSE ≈ 0.0010267

Normal 95%:  0.3837 ± 1.96(0.03204) = [0.3209,\ 0.4465]
Percentile 95%:  [0.327,\ 0.449]

Close but not identical — a small amount of skew is normal even here; comment on the direction of any shift rather than expecting an exact match.

5.7Spot-the-bug — resampling loop (v25)

bootSample1 <- sample(data, size=length(data), replace=FALSE)

bootSample2 <- for(i in 1:length(data)){
  bootFunc(sample(data, size=nrep, replace=TRUE))
}

bootSample3 <- for(i in 1:nrep){
  bootFunc(sample(data, size=length(data), replace=TRUE))
}

bootSample4 <- for(i in 1:nrep){
  mean(sample(data, size=length(data), replace=TRUE))
}
Only bootSample3 is correct.

bootSample1 uses replace=FALSE — that's just a reshuffling of the exact same data, not a bootstrap resample; every "replicate" would contain identical values. bootSample2 swaps the two numbers: it loops length(data) times instead of nrep, and draws samples of size nrep instead of length(data) — both dimensions are wrong. bootSample4 hardcodes mean() instead of calling the actual estimator bootFunc — only correct by accident if the estimator of interest happens to be the mean. bootSample3 has both numbers in the right place: loop nrep times, resample size length(data) with replacement, apply the real estimator each time.

5.8Spot-the-bug — MSE formula (v25)

b.mse1 <- var(bootEstB) - (mean(bootEstB) - b.MLE(data))^2
b.mse2 <- sd(bootEstB)  - (mean(bootEstB) - b.MLE(data))^2
b.mse3 <- sd(bootEstB)  - (mean(bootEstB))^2
None of the three are correct — a genuine possibility to keep in mind, don't assume one option must be right.

b.mse1 has the right pieces (variance and squared bias) but the wrong sign: MSE is variance plus bias², not minus. b.mse2 repeats that sign error and additionally uses sd() where var() belongs (SE and variance are not interchangeable in this formula). b.mse3 compounds both problems and also drops the subtraction of b.MLE(data) entirely, squaring the raw bootstrap mean instead of the bias. The correct line is:

b.mse.correct <- var(bootEstB) + (mean(bootEstB) - b.MLE(data))^2

5.9Spot-the-bug — CI formulas (v25)

normalBootCI1 <- b.MLE(data) + c(-1,1)*qnorm(0.95)  * sd(bootEstB)
normalBootCI2 <- b.MLE(data) + c(-1,1)*qnorm(0.975) * var(bootEstB)

percentBootCI_v1 <- quantile(bootEstB, probs=c(0.025,0.975))
percentBootCI_v2 <- 1 - quantile(bootEstB, probs=c(0.025,0.975))
Percentile: percentBootCI_v1 is exactly the definition in §5.3 — correct. percentBootCI_v2 subtracts the quantiles from 1, which isn't a bootstrap CI for anything meaningful here — wrong.
Normal: neither is fully right as a 95% interval. normalBootCI1 uses qnorm(0.95)≈1.645, the multiplier for a 90% two-sided interval (or a one-sided 95% bound) — wrong z for a stated 95% two-sided CI. normalBootCI2 uses the right z (qnorm(0.975)≈1.96) but multiplies by var() instead of sd() — variance is in squared units and will make the interval far too wide. The correct line combines the right pieces of each: b.MLE(data) + c(-1,1)*qnorm(0.975)*sd(bootEstB).

5.10Common exam pitfalls

  • replace=TRUE is non-negotiable — without it there's no bootstrap.
  • Bias is θ̂* − θ̂ (bootstrap mean minus the original estimate), never the other way around — the sign matters for the bias-corrected estimate.
  • MSE adds variance and squared bias; check whether you're given sd() or var() before plugging in.
  • Percentile CI uses the quantiles directly; Basic CI reflects them around 2θ̂ — write out both formulas rather than guessing which one a given line of code matches.
  • If asked to "compare" the CI types, look at whether mean(θ̂*) and median(θ̂*) differ from θ̂ — that skew is exactly what drives Normal and Percentile apart.
