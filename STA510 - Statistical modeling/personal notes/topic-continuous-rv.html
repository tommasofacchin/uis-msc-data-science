1.1Probability density function (pdf)

f(x) is the pdf of a continuous r.v. X if and only if:

1. f(x) ≥ 0 for all x
2. ∞−∞ is shorthand — properly: ∫−∞∞ f(x) dx = 1
3. P(a < X < b) = ∫ab f(x) dx

Unlike the discrete case, P(X = a) = 0 always for continuous X — so P(X ≤ a) = P(X < a), and it never matters whether an inequality in a probability statement is strict.

Exam step 1 — whenever a density contains an unknown constant c, the very first thing to do is solve ∫ f(x) dx = 1 for c. This is almost always graded as its own step, so never skip writing it out even if the value is "obvious".

1.2Cumulative distribution function (cdf)

F(x) = P(X ≤ x) = ∫−∞x f(t) dt   ⇔   F′(x) = f(x)

Once you have F, every interval probability is just a subtraction — no new integration needed:

P(a < X < b) = F(b) − F(a)  ·  P(X > a) = 1 − F(a)

This matters for speed under exam conditions: derive F(x) once, then answer several sub-questions from it instead of re-integrating f each time.

1.3Expectation and variance

E(X) = ∫−∞∞ x f(x) dx  (often written μ)

E(g(X)) = ∫−∞∞ g(x) f(x) dx  — for any function g, e.g. g(X)=X², 1/X, eX...

Var(X) = E[(X−μ)²] = E(X²) − E(X)²   (the second form is almost always faster)

SD(X) = √Var(X)
Rule of thumb — about 95% of the distribution's mass typically falls in [μ − 2σ, μ + 2σ]. Handy for sanity-checking an answer, not a substitute for the exact calculation.

1.4Worked example (full exam-style walkthrough)

Let X have density f(x) = c·x² for 0 ≤ x ≤ 3 (and 0 otherwise). Find c, E(X), Var(X), F(x), and P(1 < X < 2).

Step 1 — normalizing constant.

∫03 c x² dx = c·x³3│03 = c·9 = 1  ⇒  c = 1/9

Step 2 — expectation and variance.

E(X) = ∫03 x·19x² dx = 19·x⁴4│03 = 8136 = 2.25

E(X²) = ∫03 x²·19x² dx = 19·x⁵5│03 = 24345 = 5.4

Var(X) = 5.4 − 2.25² = 5.4 − 5.0625 = 0.3375

Step 3 — cdf.

F(x) = ∫0x 19t² dt = x³27,   0 ≤ x ≤ 3

Step 4 — interval probability, reusing F.

P(1<X<2) = F(2) − F(1) = 827 − 127 = 727 ≈ 0.259
Bonus — transformation. With the same f, E(1/X) = ∫03 (1/x)·(1/9)x² dx = (1/9)∫03 x dx = (1/9)(9/2) = 0.5. This is the pattern for any "find E(g(X))" sub-question: plug g(x) straight into the definition, integrate over the support, done.

1.6Common exam pitfalls

  • Forgetting the support: a piecewise density (0 outside [a,b]) means every integral's limits are a to b, not −∞ to ∞ — writing the wrong limits is the single most common lost point here.
  • Using Var(X)=E[(X−μ)²] directly when E(X²)−E(X)² is faster and less error-prone (fewer terms to expand).
  • Mixing up f and F in a sub-question — re-read whether it asks for the density or the cumulative probability.
  • For a density with several pieces, integrate each piece over its own range when computing F(x) for an x beyond the first piece — a classic source of off-by-a-term errors.
