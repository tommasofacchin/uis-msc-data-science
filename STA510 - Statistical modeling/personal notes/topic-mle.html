3.1Idea and algorithm

Given iid data x₁,…,xn from a density f(x;θ), pick the θ that makes the observed data most likely.

  1. Write the likelihood L(θ) = ∏i=1n f(xi;θ).
  2. Take the log: l(θ) = ln L(θ) = Σ ln f(xi;θ) (sums are easier to differentiate than products).
  3. Differentiate and solve l′(θ) = 0 for θ̂.
  4. Confirm a maximum: l″(θ̂) < 0.

3.2Worked example — Exponential(λ)

L(λ) = λⁿ e−λΣxi  ⇒  l(λ) = n ln λ − λΣxi

l′(λ) = n/λ − Σxi = 0  ⇒  λ̂ = n/Σxi = 1/X

l″(λ) = −n/λ² < 0 ✓ maximum

3.3Worked example — Rayleigh distribution (real data)

Wave heights are often modelled by the Rayleigh density f(x)=(x/θ²)e−x²/(2θ²), x>0 — a special case of Weibull. For 20 measured wave heights:

L(θ) = ∏xiθ2ne−Σxi²/(2θ²)  ⇒  l(θ) = const − 2n ln θ − 12θ²Σxi²

l′(θ) = −2n/θ + Σxi²/θ³ = 0  ⇒  θ̂ = √(12nΣxi²)

For the 20 measurements 3.5, 2.0, 3.3, 1.8, 1.6, 1.5, 2.0, 0.8, 2.2, 1.1, 1.8, 1.1, 1.9, 4.0, 2.5, 1.9, 1.5, 3.5, 1.2, 5.3, this gives θ̂ ≈ 1.76. Compare to the moment estimator θ̂₂ = X√(2/π) ≈ 1.78 (using E(X)=θ√(π/2)) — MLE is generally preferred, but bootstrap (see the Bootstrap page) lets you actually check which performs better by simulation.

3.4Worked example — MLE is not automatically the best estimator (v25)

X∼Pareto(a,b), a known. MLE: b̂ = n / Σln(Xi/a). Given (without re-deriving): E(b̂)=nb/(n−1) and E(b̂²)=n²b²/[(n−1)(n−2)] — so b̂ is biased (overestimates b, though the bias →0 as n→∞):

Var(b̂) = n²b²/[(n−1)²(n−2)]  ⇒  MSE(b̂) = Var(b̂)+bias² = b²(n+2)/[(n−1)(n−2)]

An alternative estimator b* = (n−1)/Σln(Xi/a) = n−1nb̂ rescales away the bias exactly:

E(b*) = n−1n·nbn−1 = b  (unbiased!)  ⇒  MSE(b*) = Var(b*) = b²/(n−2)

Comparing: MSE(b̂)=b²(n+2)/[(n−1)(n−2)] vs. MSE(b*)=b²(n−1)/[(n−1)(n−2)] — since n+2 > n−1 for every n, b* has strictly smaller MSE than the raw MLE, always. A one-line bias correction (multiply by (n−1)/n) strictly improves on the MLE here — direct proof that "MLE" and "best estimator" are not synonyms (echoing the Rayleigh MLE-vs-moment comparison in §3.3).

3.5Properties: bias, variance, MSE

bias(θ̂) = E(θ̂) − θ  ·  MSE(θ̂) = Var(θ̂) + bias(θ̂)²

An MLE is not automatically unbiased (the Rayleigh θ̂ above is not exactly unbiased for finite n) — check by simulation if it matters, or use the bootstrap to estimate the bias directly from data.

3.6Sample size for a target precision (h25)

Same CLT-based logic as the CLT & CIs page: if θ̂ is approximately normal with known/estimated variance, solve for n so that the margin of error is below a target e:

n > z²α/2·Var1(θ̂)/e²  (where Var₁ is the per-observation contribution to Var(θ̂))

Worked (h25): rainfall X∼Exponential(β), MLE β̂=X with Var(β̂)=β²/n (from §3.2's Exponential MLE). How many measurements for a 95% margin of at most 1mm, using the pilot estimate β̂=9.29?

1.96·β̂/√n ≤ 1  ⇒  n ≥ (1.96×9.29)² ≈ 331.5  ⇒  n=332

3.7Common exam pitfalls

  • Always take the log before differentiating — differentiating the raw likelihood directly is far more error-prone with products.
  • Don't skip the second-derivative check — some exam densities have a stationary point that is a minimum or saddle, not a maximum.
  • Watch the support of the parameter — e.g. θ>0 — when solving l′(θ)=0, discard any root outside the valid range.
