4Monte Carlo methods for integrals

4.1Crude Monte Carlo

θ = ∫01 g(x) dx = E(g(X)), X∼Unif[0,1]  ⇒  θ̂ = g(X) = (1/n)Σg(Xi)

General interval: θ=∫ab g(x)dx = (b−a)E(g(X)), X∼Unif[a,b]  ⇒  θ̂CMC = b−anΣg(Xi)

4.2General decomposition & higher dimensions

For θ=∫A g(x)dx with an unbounded or oddly-shaped domain, split g(x) = h(x)f(x) where f is some probability density on A you know how to sample:

θ = ∫A h(x)f(x)dx = E(h(X))  ⇒  θ̂GCMC = (1/n)Σh(Xi),   Xi∼f

Extending to several dimensions costs almost nothing — simulate each coordinate from its own uniform (or other) proposal and average the integrand at the joint draws:

∫a1a2∫b1b2∫c1c2 f(x,y,z)\,dz\,dy\,dx ≈ (a2−a1)(b2−b1)(c2−c1)nΣf(Xi,Yi,Zi)

Cost grows only linearly with dimension (one extra proposal per axis) — the reason MC beats numerical quadrature for high-dimensional integrals.

4.3Precision, standard error, sample size

SD(θ̂) = K√n — precision only improves as √n, so doubling accuracy costs 4× the simulations

For crude MC on [a,b]: SD(θ̂CMC) = (b−a)·σg(X)/√n, with σ²g(X) estimated by the sample variance of g(X1),…,g(Xn). Since the estimator is an average, the CLT gives an approximate (1−α)100% CI:

θ̂ ± zα/2·SD(θ̂)

Solving for the n needed to keep the margin under a target ε:

n > z²α/2(b−a)²σ²g(X)/ε²  (for a probability estimate, p(1−p)<0.25 always, so n>z²α/2/4ε² — at 95%, simply n>1/ε²)
Don't confuse SD(individual draws) with SD(the estimator). A question may hand you the sample sd of the raw simulated values g(Xi) (or of 0/1 indicators) — that is not SD(θ̂) yet; you still need to divide by √n (and multiply by b−a if applicable) before building a CI.

4.4Antithetic variables

If U∼Unif[a,b] then V=a+b−U is also Unif[a,b] but negatively correlated with U. When g is monotonic on [a,b], this makes g(U) and g(V) negatively correlated too, which lowers the variance of the average:

θ̂AT = b−an[Σg(Ui) + Σg(Vi)],   n/2 pairs, Vi=a+b−Ui
Check monotonicity first — if g is not monotonic over the whole interval (e.g. an even function symmetric about the midpoint), U and V can land in regions where g moves the same direction, giving little or no variance reduction — sometimes even worse than crude MC. Always state this when a question asks you to "assess whether antithetic variables will help".

For a general proposal f with known F⁻¹, the antithetic pair is Xi=F⁻¹(Ui), Yi=F⁻¹(1−Ui) — for N(μ,σ²) specifically, Xi=μ+σZi, Yi=μ−σZi.

4.5Importance sampling

θ = ∫A g(x)f(x)f(x)dx = Eg(X)f(X)  ⇒  θ̂IS = (1/n)Σ g(Xi)/f(Xi),   Xi∼f

Pick f to be shaped like g (so the ratio g/f is nearly flat) — the flatter that ratio, the smaller Var(g(X)/f(X)). If f's support is bigger than A, add an indicator: θ̂ = (1/n)Σ g(Xi)I(Xi∈A)/f(Xi).

Importance sampling does not always reduce variance — a poorly matched proposal (thin tails relative to g, or the wrong shape) can make Var(θ̂IS) larger than the crude estimator's. This exact question ("does IS always help — justify") has been asked directly (v24); the honest answer is no, and the diagnostic is to check whether the importance weights g(Xi)/f(Xi) stay bounded rather than blowing up for a few draws.

4.6Past-exam gallery — generalized MC via an auxiliary distribution

h22 gives four integrals and asks for MC estimators built from different proposals — the exact pattern to recognize and reuse:

A = ∫0∞ x3/2e−2xdx ≈ 0.234996 — write x3/2e−2x = (x3/2/2)·[2e−2x], the bracket is the Exponential(rate=2) density
⇒ Â = (1/n)Σ Xi3/2/2,   Xi∼Exp(rate=2)

B = ∫02 x3/2e−2xdx ≈ 0.198282 — same proposal, truncate with an indicator:
⇒ B̂ = (1/n)Σ (Xi3/2/2)·I(Xi<2),   Xi∼Exp(rate=2)

C = ∫−11 √(1+x³)dx ≈ 1.952757,   D = ∫−11 √(1+x⁴)dx ≈ 2.178859 — both crude MC from Unif(−1,1):
⇒ Ĉ = 2·√(1+X³),   D̂ = 2·√(1+X⁴)
Same exam's antithetic follow-up (part f) — pair X with −X (since a+b=0 on [−1,1]) for both C and D. x³ is monotonic on [−1,1] (so is 1+x³ and its square root) ⇒ antithetic helps for C. x⁴ is not monotonic (it's symmetric, decreasing then increasing) ⇒ antithetic gives little or no improvement for D — exactly the §4.4 warning, tested concretely.

h24 asks the same trick for I=∫a∞ ln(x)/xbdx using a Pareto(a,b) proposal (density b·ab/xb+1):

ln(x)/xbb·ab/xb+1 = x·ln(x)b·ab  ⇒  Î = (1/n)Σ Xiln(Xi)/(b ab), Xi∼Pareto(a,b)

Because Pareto's F⁻¹ is closed-form (§2.4), an antithetic version is also possible here — pair Xi=a/(1−Ui)^{1/b} with Yi=a/Ui^{1/b}.

4.7Past-exam gallery — simulate-then-summarize (no closed integral)

h24: Z=5X+3Y, X∼Lognormal(μ=1,σ²=0.25), Y∼χ²2, independent. There's no need to set up an integral at all — simulate n pairs, form Zi=5Xi+3Yi, then:

E(Z) ≈ Z  ·  P(Z<20) ≈ (1/n)ΣI(Zi<20)  ·  P(40<Z<60) ≈ (1/n)ΣI(40<Zi<60)

This is the same "generate data, then average an indicator/function of it" idea as everything above — just without ever writing down the integral explicitly. A 3-D integral in the same exam mixes a bounded-uniform proposal for two axes with a matched proposal (e.g. half-normal, when the integrand carries an e−x²/c factor) for the unbounded one — always decompose per-axis, multiply the interval lengths / proposal normalizing constants together.

4.8Past-exam gallery — precision, CIs, and importance sampling together

v25: n=5000 draws from f(x)=20x(1−x)³ (Beta(2,4), E(X)=1/3), with Var(X)=2/63 given. Build a 95% CI for E(X) using z0.975=1.959964:

SE = √(Var(X)/n) = √((2/63)/5000) ≈ 0.002520  ⇒  margin ≈ 1.96×0.002520 ≈ 0.00494
CI ≈ X ± 0.0049  (centered near the true 1/3≈0.3333 once you plug in your own simulated X)

Same exam's importance-sampling part: estimate I=∫01 x(1−x)³dx (this is the Beta(2,4) kernel without the 20, so I=1/20 exactly) using a Beta(2,2) proposal g(x)=6x(1−x):

x(1−x)³6x(1−x) = (1−x)²6  ⇒  ÎIS = (1/n)Σ(1−Xi)²/6, Xi∼Beta(2,2)

v23 hands you summary output instead of raw data — read it carefully. For an indicator-based estimator (e.g. p̂=(1/n)ΣI(⋯)) with n=1{,}000{,}000, mean 0.166846 and reported sd=0.372839:

that sd is the spread of the individual 0/1 draws (here matching a Bernoulli sd √(p(1−p)) for p≈1/6) — not SD(p̂) yet.

SE(p̂) = 0.372839/√1{,}000{,}000 = 0.000373  ⇒  95% CI = 0.166846 ± 1.96(0.000373) ≈ [0.16612,\,0.16758]

Exact n for SD(p̂)<0.01: solve √(p(1−p)/n) < 0.01 ⇒ n > p(1−p)/0.0001 ≈ 1389 (no z involved — this asks for the estimator's sd, not a CI margin)

4.9Spot-the-bug — v24

Target: θ=∫16 g(x)dx with gx <- function(x) exp(2-x^(3/4))*x^(1/3)/2. Three candidate estimators:

Est1: x1 <- runif(Nsim/2,1,6); x2 <- 5-x1; Est1 <- 5*mean(gx(c(x1,x2)))

Est2: x <- rgamma(Nsim,4,1.4)
      Est2 <- mean( dgamma(x,4,1.4) / (gx(x)*(x<6 & x>1)) )

Est3: x <- rgamma(Nsim,4,1.4)
      Est3 <- mean( gx(x)*(x<6 & x>1) / dgamma(x,4,1.4) )
Only Est3 is correct.

Est1 attempts an antithetic pairing on [1,6], but the correct partner of x1 is a+b−x1 = 1+6−x1 = 7−x1, not 5−x1 (that's using b−a instead of a+b). Since x1∈[1,6], 5−x1 can land as low as −1 — outside the integration domain entirely — so this estimator is simply wrong, not just less efficient.

Est2 has the importance-sampling ratio inverted: it computes fproposal(x)/g(x) instead of g(x)/fproposal(x) — this doesn't estimate θ at all.

Est3 matches §4.5 exactly: g(x)I(1<x<6)/fproposal(x), correct.

4.10Common exam pitfalls

  • Read whether the question wants the point estimator, the standard error, or a full CI — they're graded as separate steps and each has its own formula.
  • For antithetic variables, always check (or explicitly state) monotonicity of the integrand before claiming variance reduction — see §4.4 and the h22 C-vs-D contrast.
  • For importance sampling, match the proposal's support to the integration domain, or add the indicator trick — and never assume IS automatically helps.
  • When several R estimators are given, check the antithetic reflection formula (a+b−x, not b−a−x) and the direction of every importance-sampling ratio individually.
