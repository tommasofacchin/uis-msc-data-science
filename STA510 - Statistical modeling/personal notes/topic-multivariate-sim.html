6.1Multivariate normal — setup

f(x) = 1(2π)d/2|Σ|1/2 exp{−0.5(x−μ)ᵗΣ⁻¹(x−μ)},   X∼Nd(μ,Σ)

with μi=E(Xi), σii=Var(Xi), σij=Cov(Xi,Xj). Build Σ from correlations via σij=ρijσiσj.

6.2Algorithm — Cholesky decomposition

The standard MVN Z∼Nd(0,I) is trivial: just d iid N(0,1) draws. For a linear transform CZ+b ∼ Nd(b,CCᵗ), so pick C with CCᵗ=Σ (its Cholesky factor):

  1. Find C such that CCᵗ=Σ (Cholesky, or spectral/SVD).
  2. Generate z=(z₁,…,zd), iid N(0,1).
  3. Return x = Cz + μ.

In R: mvtnorm::rmvnorm(n, mean, sigma) implements exactly this (with a choice of decomposition).

6.4Alternatives: Gibbs and random-walk M-H

Cholesky gives exact, independent draws — always prefer it when the target really is multivariate normal (or built from one). When it isn't, two Markov-chain alternatives from the MCMC page can simulate the same joint distribution, at a cost:

  • Gibbs sampler — cycles through univariate conditionals; exact draws from each conditional, but successive draws of the vector are correlated (not iid).
  • Random-walk M-H — proposes the whole vector at once; simplest to set up for an arbitrary target, but least efficient (lowest effective sample size per iteration) of the three.
Efficiency ranking for a genuinely multivariate-normal target: Cholesky (iid, no autocorrelation) > Gibbs (correlated, but each step exact) > RWMH (correlated and each step only approximate/rejected sometimes). The gap matters most when you need the tails or a rare joint event precisely.

v23 asks you to recognize all three from R code, for a bivariate N(0,Σ) target with Σ=[[1,0.9],[0.9,1]]:

# (a) Gibbs -- each line samples one coordinate from its exact conditional
x1 <- rnorm(1, mean=rho*x2, sd=sqrt(1-rho^2))
x2 <- rnorm(1, mean=rho*x1, sd=sqrt(1-rho^2))

# (b) Random-walk M-H -- proposes the whole vector, accepts via a density ratio
x.prop <- x[,i-1] + rnorm(2)
alpha  <- min(1, mvtnorm::dmvnorm(x.prop,...) / mvtnorm::dmvnorm(x[,i-1],...))

# (c) Cholesky -- exact, iid draws, no accept/reject at all
L      <- t(chol(Sigma))
x[,i]  <- L %*% rnorm(2)

Asked which to prefer: Cholesky — it's exact and produces iid draws directly, with no tuning and no wasted proposals, whenever (as here) the target is already known to be multivariate normal.

6.5Common exam pitfalls

  • Building Σ from correlations: multiply by both standard deviations, not variances — a very common slip.
  • Σ must be symmetric positive semi-definite — if a computed Σ fails Cholesky in R, double check the correlation values are consistent (e.g. can't all three pairwise correlations be simultaneously extreme).
  • When asked to "compare simulation methods", answer in terms of independence of draws and computational cost per effective sample, not just "which is faster to code".
